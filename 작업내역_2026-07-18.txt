[8] Vercel 배포
  - 방식: GitHub 연동 없이 `npm run build` 로 만든 dist 폴더만 Vercel CLI로
    직접 배포
  - 프로젝트: kimjimin07122-sudos-projects/homepage
  - 문제: dist 안에서 매번 `vercel --prod` 실행 시, `npm run build` 가 dist
    폴더를 통째로 비우고 다시 만들면서 그 안에 있던 `.vercel` 프로젝트 연결
    정보도 같이 삭제되어 배포할 때마다 "Which project?" 를 다시 물어봄
  - 해결: 프로젝트 루트(temp 폴더)에 `vercel link --yes --team
    kimjimin07122-sudos-projects --project homepage` 로 기존 프로젝트를 연결
    (.vercel, .env* 는 .gitignore 에 자동 추가됨). 루트는 빌드할 때 건드리지
    않는 위치라 연결 정보가 계속 유지됨
  - 이후 배포 절차: 프로젝트 루트에서
      npm run build
      npx vercel deploy dist --prod
  - 배포 후 메인/서브 라우트(SPA 새로고침 포함) 200 정상, vercel.json 의 SPA
    리라이트 규칙도 정상 작동 확인
